# Access and Private Deck Safety

Investor and fundraising decks are private surfaces.

No deck route should be casually public.

## Access questions the backend must answer

- Who is this user?
- Which organisation/workspace do they belong to?
- Can they access this deck?
- Which surface are they trying to open?
- Is the intent presentation or workflow?
- Can they print, export, comment, edit, or share?

## Controlled surfaces

- editor
- map
- smart edit
- rebuild
- review matrix
- scroll
- play
- print
- exports
- data assets
- comments
- versions
- access

## Share links

Share-token routes should be externally accessible only after backend validation.

They should not expose workflow controls unless explicitly allowed.
