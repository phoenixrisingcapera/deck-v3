# Biotech analysis

- Separate mechanism, preclinical evidence, clinical evidence, and commercial claims.
- Map the regulatory path, endpoints, milestones, capital requirements, and likely financing sequence.
- Identify intellectual-property and partnering dependencies without assuming defensibility.
- Use current regulator or trial evidence with dates and jurisdiction.
- Never transform scientific plausibility into demonstrated efficacy.
