# Business model

- Separate observed commercial facts from proposed monetization.
- Identify payer, unit, frequency, contract motion, gross-margin drivers, implementation burden, and expansion vectors.
- Use external benchmarks as comparisons, never as the company's achieved economics.
- Test whether distribution and service intensity support venture-scale growth.
- Prefer a credible initial model plus explicit expansion logic over false precision.
