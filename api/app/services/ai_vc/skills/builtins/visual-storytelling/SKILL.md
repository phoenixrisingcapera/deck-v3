# Visual storytelling

- Assign a visual job before choosing layout: explain system, compare alternatives, show sequence, quantify evidence, or create emotional focus.
- Prefer diagrams, charts, timelines, product flows, and purposeful composition over editorial callouts.
- Preserve source or website branding when available while improving hierarchy and polish.
- Never visualize an unsupported number or imply precision that the evidence lacks.
- Keep internal methodology, citations, critique, and source summaries out of the exported slides.
