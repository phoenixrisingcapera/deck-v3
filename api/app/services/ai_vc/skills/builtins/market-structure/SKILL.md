# Market structure

- Define the category and economic unit before citing a market total.
- Separate core spend from adjacent spend and explain the boundary.
- Triangulate credible primary sources; report contradictions and stale definitions.
- Never use an undifferentiated vendor market-size figure as company evidence.
- If a defensible market number is unavailable, build the investment case from structure and economics instead of inventing TAM.
