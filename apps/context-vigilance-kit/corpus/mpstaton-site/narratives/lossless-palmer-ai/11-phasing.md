## What this slide is

Concrete phasing so the proposal reads as buildable rather than aspirational.

## Why it's here

Converts vision into scope. Pre-empts 'how long and how much' before the ask slide.

## What to surface

- Phase 1 capture (now): agents populate the aggregation layer; first briefs in the content hub
- Phase 2 interface: MCP and API connectors expose the corpus to Claude Desktop, Mobile, Web — no new UI, no seats, no adoption problem
- Phase 3 application: Augment It refit for impact giving — funder-matching, targeted narrative and visualization, scheduled data fluidity
- None requires the next to justify itself

## Visual hierarchy suggestion

Three phase columns with the standalone-value line beneath. Phase 1 visually weighted heaviest — it is the one being asked for.
