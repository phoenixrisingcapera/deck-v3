# Financial scenario

- Preserve amount, currency, unit, period, qualifier, and actual-versus-projected status.
- Use deterministic calculations with named assumptions and evidence identifiers.
- Label scenarios illustrative; never convert a benchmark into company traction.
- Prioritize revenue quality, retention, margin, capital efficiency, burn, runway, and milestone financing when evidence exists.
- If key inputs are absent, record missing proof and avoid cosmetic forecasts.
