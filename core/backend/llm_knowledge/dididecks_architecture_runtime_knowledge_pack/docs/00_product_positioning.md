# Product Positioning

DidiDecks is a venture-grade deck operating system.

It should not be positioned as only:

- a slide generator
- a dashboard mockup
- a Canva clone
- a PDF prettifier

It should be positioned as:

> A structured deck workspace where every slide element, reusable company fact, investor-facing claim, review note, and export is traceable, editable, versioned, and rebuildable.

## Core differentiator

Canva-like editors treat objects as visual objects.

DidiDecks should treat objects as visual objects plus business meaning:

```txt
headline block → problem.headline persistent field
ARR metric block → metrics.arr persistent field
founder card → person data asset + founder.bio field
market chart → market claim + evidence status
```

## Primary users

- Founders preparing investor decks
- VC analysts reviewing decks
- Accelerators and venture studios helping many companies
- Funds preparing IC memos or LP-facing summaries
- Advisors who repeatedly update company, founder, market, and metric data

## Product promise

Upload or build a deck once. Then update the business truth once and safely rebuild every affected slide.
