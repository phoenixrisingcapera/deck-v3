# VC, LP, and Due Diligence Expansion

The DidiDecks model can become stronger when the deck system understands venture context.

## Founder-facing intelligence

- pitch narrative
- problem/solution clarity
- market sizing evidence
- competitor map
- traction metric quality
- fundraising ask logic

## VC-facing intelligence

- due diligence gaps
- risk register
- IC memo readiness
- benchmark expectations by stage/sector/business model
- data room checklist
- legal/term-sheet risk classification

## LP-facing intelligence

- fund return logic
- portfolio fit
- follow-on reserve pressure
- DPI/TVPI/IRR framing
- exit path visibility
- concentration risk

These modules should be knowledge and backend-owned intelligence, not hidden frontend logic.
