# VC Investment Methodology Corpus

`corpus.json` is a curated, versioned compilation of the historical
`francisjervis/venture-capital-research` article index.

- Evidence class: `PRODUCT_KNOWLEDGE`
- Runtime role: internal VC evaluation and investment-memo methodology
- Current-market authority: none
- Customer/company factual authority: none
- Corpus version: `vc-investment-methodology.v1`

Current market, competitor, pricing, regulation, funding, exit, and why-now
claims still require separately verified `EXTERNAL_RESEARCH`. Rebuild the file
with `scripts/build_vc_methodology_corpus.py`; never insert uploaded customer
material into this corpus.

The source index is MIT licensed, Copyright (c) 2017 Francis Jervis. Linked
papers retain their own publishers and rights; this package stores the index's
metadata and abstracts with attribution, not downloaded paper files.
